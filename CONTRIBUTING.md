## 🛠 Cómo contribuir / How to Contribute

**Español 🇪🇸**

1. **Clona el repositorio:**

   ```bash
   git clone https://github.com/Lombardimn/project-pitchSide.git
   cd NOMBRE_REPOSITORIO
   npm install
   ```

2. Realiza tus cambios en una rama (`feature/nombre-de-tu-aporte`).
3. Envía un Pull Request explicando tu contribución.

**English 🇬🇧**

1. **Clone the repository:**

   ```bash
   git clone https://github.com/YOUR_USERNAME/REPO_NAME.git
   cd REPO_NAME
   npm install
   ```

2. Make your changes in a branch (`feature/your-contribution-name`).
3. Submit a Pull Request describing your contribution.
